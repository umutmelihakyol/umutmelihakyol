Günlüğüm — Ara menüsü ve ayrıntı açılış animasyonu güncellemesi

Uygulama:
1. ZIP dosyasını GitHub deposunun kök dizinine çıkar.
2. İçindeki umutmelihakyol-main klasöründeki dosyaları aynı yolların üzerine yaz.
3. Değişiklikleri commit edip yayımla.

Bu paket yalnızca değişen dosyaları içerir. Alt kategori menülerindeki yinelenen Ara öğesi kaldırılmıştır; üst sağdaki Ara düğmesi korunmuştur. Ayrıntı penceresine kısa ve hafif bir açılış animasyonu eklenmiştir. Önbellek sürümü yenilenmiştir.
