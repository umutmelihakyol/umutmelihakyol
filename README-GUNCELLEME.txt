Günlüğüm — Ayrıntı sayfası modernizasyonu

Bu paket yalnızca güncellenen dosyaları içerir. ZIP içeriğini GitHub deponun kök dizinine çıkarıp mevcut dosyaların üzerine yaz.

Değişen dosyalar: ortak ayrıntı penceresi, anime kapak yönü davranışı, paylaşılabilir inceleme kartı başlığını okuyan seçici, kategori HTML dosyalarında önbellek sürümleri ve servis çalışanı sürümü.

Yayınlamadan sonra oyun/film/dizi/anime ayrıntı pencerelerini masaüstü ve mobilde kontrol et. Canlı siteye otomatik yayın yapılmamıştır.
