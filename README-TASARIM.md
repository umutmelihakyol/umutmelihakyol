# Günlüğüm — Archive Editorial

Günlüğüm arayüzü, sıcak kâğıt tonları ve mat kiremit/oliv vurgularıyla editoryal bir kişisel arşiv görünümüne geçirildi. Başlıklarda Fraunces, gövde ve arayüz metinlerinde IBM Plex Sans kullanılır.

Ortak stil dosyası `assets/css/archive-editorial.css`, sayfalar arası gezinme betiği `scripts/site-nav.js` dosyasıdır. Ana sayfa, medya kategorileri, arama, istatistik, kişiler, Technopat, çekiliş, maliyet ve yönetim paneli aynı tasarım sistemini kullanır. Açık ve koyu tema desteklenir.

Mevcut içerik verileri ve uygulama işlevleri korunmuştur. Service Worker v34 olarak güncellenmiş, yeni CSS ve JavaScript dosyaları çevrimdışı temel varlık listesine alınmıştır.
