Platform Entegrasyonları (Steam / Letterboxd / MyAnimeList)

Dış platformlardaki kütüphaneni veya izleme geçmişini tek tıkla sitenin formatına dönüştür. Zaten mevcut olan kayıtlar (isim eşleşmesine göre) otomatik atlanır.

🎬 Letterboxd (CSV İçe Aktar → Filmler)

Letterboxd Settings → Import & Export → Export Your Data üzerinden indirdiğin ZIP içindeki ratings.csv, diary.csv, watched.csv veya watchlist.csv dosyasını seç.

🎌 MyAnimeList (XML Dosyası veya Kullanıcı Adı → Animeler)

İstersen MAL'dan dışa aktardığın .xml dosyasını yükle (.xml.gz ise önce arşivden çıkar), istersen de herkese açık profilinin kullanıcı adını yaz.

🎮 Steam Kütüphanesi (API veya JSON → Oyunlar)

Steam kütüphanendeki oyunları ve oynama sürelerini (saat olarak) çeker. Doğrudan çekmek için 64-bit SteamID ve Steam Web API anahtarı gir ya da tarayıcıdan aldığın IPlayerService/GetOwnedGames JSON çıktısını aşağıya yapıştır.

Otomatik Yedekleme ve Geri Yükleme

Her kayıt işleminden önce mevcut arşivin güvenlik kopyası alınabilir. GitHub'daki backups/latest.json dosyası son otomatik kopyayı tutar; önceki sürümler de GitHub commit geçmişinde kalır.

Otomatik yedekleme etkin. İlk kayıt öncesinde yedek oluşturulacak.

Yedekten geri yükle

Daha önce indirdiğin Günlüğüm JSON yedeğini seçebilirsin. Yedekte bulunan kategoriler GitHub'a geri yazılır; dosyada bulunmayan kategoriler değiştirilmez.

Henüz bir yedek seçilmedi.

Geri yükleme öncesinde mevcut arşiv ayrıca yedeklenir. Geri yükleme, yedekte bulunan kategorilerin mevcut kayıtlarını tamamen değiştirir; işlem birden fazla GitHub commit'i oluşturur.

Kontrol edilenler: boş veya yinelenen başlıklar/ID'ler, hatalı puanlar ve durumlar, eksik kapak veya temel bilgiler, geçersiz bağlantı biçimleri ve bitirilmiş kayıtlardaki eksik alanlar. Görsel adresinin gerçekten çalışıp çalışmadığı bu kontrolün parçası değildir.

Yapılandırma Ayarları (config.js)

GitHub deponuzdaki config.js dosyasını buradan doğrudan güncelleyebilirsiniz. (Vault anahtarını değiştirmek için üstteki Çıkış'ın yanından Kurulum ekranını da kullanabilirsiniz).

Kategori Tanımları (categories.js)

Sitedeki kategorilerin isimlerini, durum etiketlerini veya süre birimlerini doğrudan düzenleyin.

Technopat İçerik Yönetimi

Ana sayfadaki Technopat bölümünde görünen inceleme ve rehber kartlarını buradan yönetebilirsin. Eklediğin, düzenlediğin veya sildiğin değişiklikler önce bu ekranda tutulur; GitHub'a göndermek için ayrıca kaydetmelisin.

Technopat içeriklerini yüklemek için GitHub'dan Getir düğmesine bas.

Yeni Technopat kartı

Kart bağlantısı HTTPS üzerinden Technopat alan adına yönlenmelidir. Kategori, kart üzerinde filtre etiketi olarak kullanılır.

“Kartı Ekle / Güncelle” yalnızca ekrandaki taslağı değiştirir. Değişiklikleri ziyaretçilerin görmesi için üstteki “Değişiklikleri GitHub'a Kaydet” düğmesini kullan.
